Content Production Hub

O Content Production Hub é um projeto da Destak em preparação para Windows. Foi concebido para organizar vídeos próprios ou autorizados e facilitar o envio para o TikTok.

A integração com o TikTok está em fase de preparação. O fluxo previsto permite selecionar o vídeo no Windows, autorizar a conta TikTok e enviar o ficheiro para concluir a publicação no TikTok.
